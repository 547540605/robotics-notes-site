笔记 32：把 RNEA 收束成 M(q)、h(q,q̇)、g(q)

31 的递归算法能在给定状态时算出关节力矩。对二维两连杆，它还能被整理成一个非常重要的结构式：哪部分来自加速惯性，哪部分来自运动耦合，哪部分只是悬停对抗重力。后续轨迹约束、PID 前馈与计算力矩控制都从这里开始。

先把一个关节扭矩看成四份账

τ = M(q)q̈ + h(q,q̇) + g(q) + τ_friction + τ_external
这一页具体求：
平面两连杆的 M,h,g，并观察它们如何随姿态、速度和加速度改变。
这一页故意不做：
不引入摩擦/外载荷数值，不直接做真机 torque command，不把 h 与唯一的 C 矩阵混为一谈。

1. 先固定坐标约定，否则重力项符号没有讨论基础

本页模型

  • 二维竖直平面，x 向右、y 向上；
  • q₁=0 时大臂沿 +x；q₂=0 时小臂与大臂共线；
  • 重力向 -y；连杆长 l₁，质心距 r₁,r₂；
  • I₁,I₂ 为各杆绕质心、垂直平面的转动惯量。

先看四个状态

  • q 决定构型与重力方向；
  • q̇ 决定向心/科氏式速度耦合；
  • q̈ 决定加速惯性需求；
  • 参数 m,r,I 决定同一动作“有多沉”。

2. M(q)：让关节产生加速度要付的惯性成本

M(q)= [ M₁₁  M₁₂ ; M₁₂  M₂₂ ] M₁₁=I₁+I₂+m₁r₁²+m₂(l₁²+r₂²+2l₁r₂cos q₂) M₁₂=I₂+m₂(r₂²+l₁r₂cos q₂),   M₂₂=I₂+m₂r₂²
读法：矩阵不是“关节 1 一个惯量、关节 2 一个惯量”的对角表。M₁₂ 表示肘关节加速也会影响肩关节扭矩，反之亦然；cos q₂ 表示伸直与折叠时等效惯量不同。

3. h(q,q̇)：即使 q̈=0，匀速联动也可能需要扭矩

h₁=-m₂l₁r₂sin q₂(2q̇₁q̇₂+q̇₂²),   h₂=m₂l₁r₂sin q₂q̇₁²

它包含什么

常被称为科氏/离心项或速度耦合项。它来自连杆高速转动时，质心速度方向不断变化；不是摩擦，也不是重力。

一个细节很重要

很多教材写成 C(q,q̇)q̇。C 矩阵本身不唯一，不同但合法的 C 都可能给出同一个 h=Cq̇。工程中应核对最终向量 h，而不是执着于某一份 C 的排版。

4. g(q)：悬停也需要的姿态相关扭矩

g₁=(m₁r₁+m₂l₁)g cos q₁ + m₂r₂g cos(q₁+q₂) g₂=m₂r₂g cos(q₁+q₂)
读法：当手臂水平伸出，cos 接近 1，重力力臂最大；当连杆竖直，重力作用线接近穿过关节，扭矩可接近零。重力项只与姿态有关，不依赖关节速度。

6. 从这页走向 CTC，不是把公式再背一遍

轨迹规划给什么

给期望 q_d(t),q̇_d(t),q̈_d(t)。没有期望加速度，逆动力学前馈就没有完整输入。

计算力矩控制怎么用

先用模型算 M(q)q̈_d+h(q,q̇)+g(q) 作为前馈，再加位置/速度误差的 PD 反馈，抵抗模型误差与扰动。

带走的四个判断

为什么手臂不动时也可能需要扭矩？

此时 q̇=q̈=0，惯性和速度耦合项为零，但重力项 g(q) 仍在。水平悬停尤其需要关节提供反重力力矩。

为什么把小臂折起来，肩关节的惯量会变化？

小臂质量相对肩关节的分布随 q₂ 改变，M₁₁ 与 M₁₂ 中的 cos q₂ 正在描述这个几何事实。

h 为零是否代表没有运动？

不一定。若 q̇ 不为零但姿态恰好让 sin q₂=0，特定两连杆模型的 h 可能瞬时为零；运动和惯性仍然存在，M 与其他项照样可能产生扭矩。

为什么本页不直接给一个唯一的 C 矩阵？

真正被动力学方程物理确定的是 h=Cq̇。不同构造方式的 C 可能不同，但只要乘以 q̇ 后得到同一 h，就可描述同一动力学。先掌握 h 的来源更不容易被符号排版误导。
