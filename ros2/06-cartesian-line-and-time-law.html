ROS 2 全景看板 · ROS2-05：连续选支 · 04–13 路线

ROS 2 工程实战 06：笛卡尔直线与五次时间律

把“从 A 到 B”变成连续目标点列。机械臂的关节角通常不是直线，但末端在 base_link 中必须是直线。

工程痛点：关节平滑，不代表末端走直线

即使让 joint1, joint2, joint3 各自做漂亮的三次或正弦曲线，机械臂末端 tool0 在三维空间中仍会走出弯曲弧线。若任务要求沿边缘靠近、沿直线插入或避开固定区域，路径必须先在笛卡尔空间（base_link 三维坐标）按直线生成每一时刻的末端目标点，再逐点经 IK 变成关节角。

① 定起点 A、终点 B同一 base_link 三维坐标
② 算路程比例 s(t)0→1 走完全程的几成
③ 算末端目标点 P(t)时刻 t 的 (x, y, z) 坐标
④ 逐帧连续 IK由 P(t) 解出关节角 q(t)
⑤ 发布显示驱动 RViz 数字孪生
本篇边界：仍然只驱动 RViz 数字孪生。发布到 /joint_states 是显示状态，不是执行器命令；真实控制器的 JointTrajectory 在 ROS2-13 再接入。

1. 先对齐所有符号与变量含义，再写直线公式

在看任何公式前，先把本篇出现的每一个符号代表什么物理对象、在哪个坐标系、是什么维度和单位彻底定死：

符号物理含义（到底是谁？）类型 / 维度所属坐标系与单位
\(\boldsymbol{A} = (x_A, y_A, z_A)\)直线起点：机械臂末端 tool0 出发时刻的目标坐标（固定常数，本例取 \((0.50, 0.00, 0.65)\)）三维位置向量 \(\mathbb{R}^3\)base_link，单位 \(\text{m}\)
\(\boldsymbol{B} = (x_B, y_B, z_B)\)直线终点：机械臂末端 tool0 结束时刻的目标坐标（固定常数，本例取 \((0.40, 0.30, 0.75)\)）三维位置向量 \(\mathbb{R}^3\)base_link，单位 \(\text{m}\)
\(\boldsymbol{B} - \boldsymbol{A}\)全程总位移向量：\((x_B-x_A,\ y_B-y_A,\ z_B-z_A)\)，从起点指向终点的固定三维增量；其模长 \(L = |\boldsymbol{B}-\boldsymbol{A}|\) 为直线段总长度三维位移向量 \(\mathbb{R}^3\)base_link，单位 \(\text{m}\)
\(t\)当前时间：从运动开始计时的秒数，取值范围 \(0 \le t \le T\)标量（随时间递增）单位 \(\text{s}\)（秒）

\(u = t/T\)归一化时间进度：当前时间过去了总时长的百分之几，取值 \(0 \le u \le 1\)无量纲标量无单位（\(0\sim 1\)）
\(s(t)\) 或 \(s(u)\)归一化路程进度：时刻 \(t\) 末端应该走完全程线段的百分之几，取值 \(0 \le s \le 1\)（\(s=0\) 在 \(\boldsymbol{A}\)，\(s=0.5\) 在中点，\(s=1\) 到 \(\boldsymbol{B}\)）无量纲标量函数无单位（\(0\sim 1\)）
\(\boldsymbol{P}(t) = (x(t), y(t), z(t))\)时刻 \(t\) 末端 tool0 的期望目标位置：规划器算出的“这一刻末端应该在直线的哪个三维坐标点”。它就是这一帧直接传给 ROS2-04 函数 solve_position_ik(x, y, z) 的三个坐标输入！三维位置向量函数 \(\mathbb{R}^3\)base_link，单位 \(\text{m}\)
\(\boldsymbol{v}(t),\ \boldsymbol{a}(t)\)时刻 \(t\) 末端 tool0 的期望线速度与线加速度：\(\boldsymbol{v}(t)=\dfrac{d\boldsymbol{P}}{dt}\)，\(\boldsymbol{a}(t)=\dfrac{d^2\boldsymbol{P}}{dt^2}\)三维向量函数 \(\mathbb{R}^3\)base_link，单位 \(\text{m/s}\)、\(\text{m/s}^2\)
\(\boldsymbol{q}(t) = (q_1(t), q_2(t), q_3(t))\)时刻 \(t\) 的关节角向量：把 \(\boldsymbol{P}(t)\) 交给 IK 与连续选支后解出的三轴关节角；\(\boldsymbol{q}_A, \boldsymbol{q}_B\) 分别代表起点 \(\boldsymbol{A}\)、终点 \(\boldsymbol{B}\) 对应的关节角三轴角度向量 \(\mathbb{R}^3\)关节空间，单位 \(\text{rad}\)

三维参数化直线方程

有了上面的定义，想求时刻 \(t\) 末端 tool0 的期望坐标 \(\boldsymbol{P}(t)\)，只需从起点 \(\boldsymbol{A}\) 出发，加上全程总位移向量 \((\boldsymbol{B} - \boldsymbol{A})\) 的 \(s(t)\) 倍（按 \(x, y, z\) 三个坐标分量展开就是右边的三条式子）：

\[\boldsymbol{P}(t) = \boldsymbol{A} + s(t)(\boldsymbol{B} - \boldsymbol{A}) \quad\Longleftrightarrow\quad \begin{cases} x(t) = x_A + s(t)(x_B - x_A) \\ y(t) = y_A + s(t)(y_B - y_A) \\ z(t) = z_A + s(t)(z_B - z_A) \end{cases}\]

为什么这一定是一条三维直线？因为 \(x(t), y(t), z(t)\) 三个坐标共用同一个标量比例 \(s(t)\)：当 \(x\) 走完全程增量的 \(30\%\) 时，\(y\) 和 \(z\) 也严格走完全程增量的 \(30\%\)，三轴增量始终成固定比例，因此点 \(\boldsymbol{P}(t)\) 永远落在连接 \(\boldsymbol{A}\) 与 \(\boldsymbol{B}\) 的三维直线段上。至于是哪一时刻 \(t\) 走到哪个比例 \(s(t)\)，由第 2 节的时间律决定。

不要做：关节空间直线插值

如果先求起点、终点的关节角 \(\boldsymbol{q}_A, \boldsymbol{q}_B\)，再按 \(\boldsymbol{q}(t) = \boldsymbol{q}_A + s(t)(\boldsymbol{q}_B - \boldsymbol{q}_A)\) 让三个关节角按比例变化，只能保证“关节角数值变化是线性的”；经过含有 \(\sin/\cos\) 的正运动学 FK 后，末端 tool0 在三维空间里走的是一条弯曲弧线。

本篇要做：笛卡尔空间直线 + 逐点 IK

先在 base_link 下按直线公式算出每一帧的末端三维坐标 \(\boldsymbol{P}(t) = (x(t), y(t), z(t))\)，再把每一个 \(\boldsymbol{P}(t)\) 交给 ROS2-04/05 的 IK 反解出 \(\boldsymbol{q}(t)\)。此时关节角曲线 \(\boldsymbol{q}(t)\) 是弯曲的，但末端 tool0 在三维空间走出的是真直线。

先拿同一组坐标走一遍：A → B

本篇始终使用 base_link 下的 A=(0.50, 0.00, 0.65) m、B=(0.40, 0.30, 0.75) m，总时长 T=3 s。先按坐标逐项相减，得到 B−A=(−0.10, +0.30, +0.10) m。这表示从 A 走到 B 时，x 减少 0.10 m、y 增加 0.30 m、z 增加 0.10 m；它不是关节角的变化量。

若此刻路径进度 s=0.5，三个坐标同时走完各自差值的一半：P=A+0.5(B−A)=(0.45, 0.15, 0.70) m。注意同一个 0.5 乘在 x、y、z 上，才保证这个点真的在三维直线上。

A、B 和 P 都是末端位置，不是三个关节角；P 只有经过 04 求 IK、05 按上一帧选支后，才会变成这一帧的 q=(q1,q2,q3)。

2. 为什么不用匀速突起突停？先分清谁是位置、速度、加速度

物理上速度的定义就是位置随时间的变化率 \(\boldsymbol{v}(t) = \dfrac{d\boldsymbol{P}}{dt}\)。因为这里的 \(\boldsymbol{A}\)、\(\boldsymbol{B}\) 和 \(\boldsymbol{P}(t)\) 都定义在地面固定的底座坐标系 base_link 下（坐标轴本身不随时间旋转），所以求末端线速度就是直接对坐标 \(\boldsymbol{P}(t)\) 关于时间 \(t\) 求导。

① 为什么“对 P(t) 求导”会变成“对 s(t) 求导”？

它们不是求了两次不同的导，而是同一个等式的左边和右边！把 \(\boldsymbol{P}(t) = \boldsymbol{A} + s(t)(\boldsymbol{B}-\boldsymbol{A})\) 代入求导：

  • 等号右边的起点 \(\boldsymbol{A} = (0.50, 0.00, 0.65)\) 是固定死数字，对 \(t\) 求导为 \(\boldsymbol{0}\)；
  • 总位移 \((\boldsymbol{B}-\boldsymbol{A}) = (-0.10, 0.30, 0.10)\) 也是固定死数字，求导时作为常数系数照抄；
  • 等号右边唯一随时间 \(t\) 变化的只有 \(s(t)\)！因此：
\[\underbrace{\boldsymbol{v}(t) = \frac{d\boldsymbol{P}}{dt}}_{\text{想求的末端线速度}} = \underbrace{\frac{ds}{dt}}_{\text{必须先算出的 }s\text{ 的导数}} \cdot \underbrace{(\boldsymbol{B}-\boldsymbol{A})}_{\text{固定死数字}}\] \[\underbrace{\boldsymbol{a}(t) = \frac{d^2\boldsymbol{P}}{dt^2}}_{\text{想求的末端线加速度}} = \underbrace{\frac{d^2s}{dt^2}}_{\text{必须先算出的 }s\text{ 的二阶导}} \cdot \underbrace{(\boldsymbol{B}-\boldsymbol{A})}_{\text{固定死数字}}\]

拿 \(x\) 轴数字举例：\(x(t) = 0.50 + s(t)\times(-0.10)\)。求速度 \(v_x(t)=\dfrac{dx}{dt}\) 时，常数 \(0.50\) 求导没了，就变成 \(v_x(t) = \dfrac{ds}{dt}\times(-0.10)\)。所以不先把右边的 \(\dfrac{ds}{dt}\) 算出来，就拿不到具体的速度数值——左卡写出这层依赖关系，右卡接着代入具体的 \(s(t)\) 公式把 \(\dfrac{ds}{dt}\) 算出来。

② 两种不同的“油门方案”：淘汰匀速，换用五次时间律

关键前提：\(s(t)\) 不是客观算出来的唯一答案，而是你作为工程师自己设计的“油门踩法”！从 \(A\) 走到 \(B\) 规定 \(T=3\text{ s}\) 走完，只要满足“第 \(0\) 秒在起点 \(s(0)=0\)、第 \(3\) 秒到终点 \(s(T)=1\)”，中间这 \(3\) 秒里怎么分配进度 \(s(t)\) 完全由你决定。就像开车走同一段路，下面不是把同一个式子变形改写，而是枪毙方案一，改用方案二：

❌ 方案一（笨方案：匀速时间律 \(s_{\text{匀速}}\)，直接作废）：假设“全程定速巡航、匀速硬跑”，则时间过了几分之几，路程就走几分之几： \[s_{\text{匀速}}(t) = \frac{t}{T}\] 求导得 \(\dfrac{ds_{\text{匀速}}}{dt} = \dfrac{1}{T}\)（常数）。这意味着第 \(0\) 秒启动瞬间速度必须从 \(0\) 直接跳到常数，终点又瞬间归零，电机受不了。因此这个方案不及格，直接扔进垃圾桶不用了！

✅ 方案二（好方案：五次时间律 \(s_{\text{五次}}\)，实际采用）：既然匀速废了，我们重新设计一个新函数模拟老司机开车：“起步轻踩油门慢加速 \(\to\) 中段跑快点把时间抢回来 \(\to\) 终点前轻踩刹车慢停下”。为此列出 6 个硬指标（方程）：

  • 起止位置对：\(s(0)=0,\quad s(T)=1\)
  • 起止速度为 0：\(s'(0)=0,\quad s'(T)=0\)
  • 起止加速度为 0：\(s''(0)=0,\quad s''(T)=0\)

6 个方程正好解 6 个未知系数，设五次多项式 \(\sum_{k=0}^{5} a_k\left(\frac{t}{T}\right)^k\) 代入上面 6 个条件解方程组，唯一解出 \(a_0=a_1=a_2=0,\ a_3=10,\ a_4=-15,\ a_5=6\)，这才得到新方案：

\[s_{\text{五次}}(t) = 10\frac{t^3}{T^3} - 15\frac{t^4}{T^4} + 6\frac{t^5}{T^5}\]

（代码里为免连写三次除法，令 \(u = t/T\)，简写为 \(s(u) = 10u^3 - 15u^4 + 6u^5\)。）对 \(t^3, t^4, t^5\) 求一阶、二阶导数：

\[\frac{ds_{\text{五次}}}{dt} = 30\frac{t^2}{T^3} - 60\frac{t^3}{T^4} + 30\frac{t^4}{T^5}\] \[\frac{d^2s_{\text{五次}}}{dt^2} = 60\frac{t}{T^3} - 180\frac{t^2}{T^4} + 120\frac{t^3}{T^5}\]

验算两端：代入 \(t=0\)，两式全为 \(0\)；代入 \(t=T\)，一阶导分子 \(30-60+30=0\)，二阶导分子 \(60-180+120=0\)。起止瞬间末端速度 \(\boldsymbol{v}=\boldsymbol{0}\)、加速度 \(\boldsymbol{a}=\boldsymbol{0}\)！

五次时间律并不改变几何路径（空间里还是同一条直线），只决定沿这条直线“什么时候走到哪里、什么时候加速与减速”。这正是几何路径与时间参数化的区别。

4. 生成器与 IK 的职责边界

这一帧怎样接到 04、05？

仍看表里的 t=1.50 s：本篇先给出 target=(0.45, 0.15, 0.70) m。把这个三维位置传给 04 的 solve_position_ik(*target)，得到 reachable 与候选列表；几何可达时，再把候选列表和上一帧实际选用的关节角 q_prev 传给 05 的 select_nearest_valid_solution(...)。最后拿选中候选的 ["q"]，得到这一帧三个关节角。这里没有从时间律直接算出关节角的捷径。

如果 04 报不可达，或 05 没有合法候选，就在这个 t、target 停下并报告；不能跳过该点继续画“直线”。初始 q_prev 应来自已知的当前关节状态，不能凭空填一个看着顺眼的角度。执行前要对整段先做同样的预扫描，见第 5 节。

下面的纯 Python 生成器对应规划中的 ~/ros2_ws/src/my_arm_motion/my_arm_motion/cartesian_path.py；它只产出目标点，不替代 04 的 kinematics_3r.py，也不是完整 ROS 节点。若你还没有创建标准包，这个路径是待建目标，不代表工作区里已有该文件。

# 规划文件：my_arm_motion/my_arm_motion/cartesian_path.py；需由调用者逐帧取样。
import math

def quintic_s(u):
    """归一化进度 u→路径比例 s；起终点速度、加速度都为零。"""
    # 调用者保证 0 <= u <= 1；越界时多项式不再表示这段路径。
    return 10*u**3 - 15*u**4 + 6*u**5

def cartesian_line(start, end, duration, dt=0.02):
    """在同一 base_link 下采样 A→B；每次 yield (t秒, (x,y,z)米)。

    这里只生成末端目标点，不求关节角；IK/限位检查交给调用方。
    """
    # start/end 都是 (x,y,z)，单位 m；duration/dt 单位 s 且必须为正。
    if duration <= 0 or dt <= 0 or len(start) != 3 or len(end) != 3:
        raise ValueError("need 3D endpoints and positive duration/dt")
    # 向上取整才能保证最后一次采样正好落在终点 B。
    steps = math.ceil(duration / dt)
    for k in range(steps + 1):
        # t 限于 [0,T]，u=t/T 是无量纲时间；s 只负责走到线段哪一处。
        t = min(k * dt, duration)
        s = quintic_s(t / duration)
        # zip 把 A/B 的 x、y、z 分别配对；同一个 s 同时插值三轴，
        # 因而目标点落在 A→B 直线上。yield 逐帧送出，不一次存整条路径。
        target = tuple(a + s * (b - a) for a, b in zip(start, end))
        yield t, target

# 在 ROS 节点中（调用顺序示意，不是可直接运行的完整节点）：
# 1) target 来自 cartesian_line
# 2) ik_result = solve_position_ik(*target)：* 把 (x,y,z) 拆成三个参数
#    若 not ik_result["reachable"]，报告 reason 并停；否则取 ik_result["candidates"]
# 3) choice = select_nearest_valid_solution(ik_result["candidates"], q_prev)
#    selected = choice["selected"]；它是含 q=(q1,q2,q3) 的字典，不是角度列表
# 4) 若 selected 为空：停止本段，并报告 t 与 target
# 5) 若存在：取 selected["q"] 给数字孪生，并令 q_prev = selected["q"]
#    真机不能把 /joint_states 当成运动命令；整段执行还须先完成预扫描

生成器不知道关节限位；IK 也不知道路径时间。二者之间只交接 target 和 selected q，这样才能准确指出路径在哪一帧失败。

5. 运行前必须做整段预扫描

检查为什么不能省失败时正确处理
逐点 IKA、B 都有解不代表中间每一点都有解或在限位内。不启动该段；缩短路径、换姿态或重设目标。
连续选支每一帧独立求解会让双解随机切换。用 ROS2-05 的 q_prev 代价选择。
FK 位置误差目标点和实际关节 FK 必须对照。记录最大误差；异常时回查 IK/URDF 约定。
速度、加速度限值五次时间律不自动保证每个关节都不过速。先拉长 T；真实控制阶段再由控制器限速。

本篇结束时的闭环

  • 你有一条从 A 到 B 的目标点列，每一点都必须经连续 IK 才能进入数字孪生。
