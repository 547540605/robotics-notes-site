ROS 2 全景看板 · ROS2-05：连续选支 · 04–13 路线

ROS 2 工程实战 06：笛卡尔直线与五次时间律

把“从 A 到 B”变成连续目标点列。机械臂的关节角通常不是直线，但末端在 base_link 中必须是直线。

工程痛点：关节平滑，不代表末端走直线

即使让 q1、q2、q3 各自做漂亮的三次或正弦曲线，末端在空间中仍会走出不可预测的曲线。若任务要求沿边缘靠近、沿直线插入或避开固定区域，路径必须先在笛卡尔空间定义，再逐点经 IK 变成关节目标。

① 定 A、B同一 base_link
② 定时间律t → s(t)
③ 取目标点P(t)
④ 连续 IK选合法 q(t)
⑤ 发布显示数字孪生
本篇边界：仍然只驱动 RViz 数字孪生。发布到 /joint_states 是显示状态，不是执行器命令；真实控制器的 JointTrajectory 在 ROS2-13 再接入。

1. 直线由位置公式定义，不由“看上去差不多”定义

起点和终点必须都写在 base_link 下。令 s 从 0 平滑增长到 1：

P(t)=A+s(t)(B-A)

无论 A、B 在三维中怎样摆放，只要同一个标量 s(t) 同时作用于三个坐标分量，P(t) 就严格落在连接 A、B 的线段上。

不要做：关节空间直线

q(t)=qA+s(qB-qA) 只保证关节向量走直线。经过 FK 后，末端一般会是一条弯曲轨迹。

本篇要做：笛卡尔空间直线

先计算 P(t)，每个 P(t) 都调用 ROS2-04/05 的 IK。关节角的曲线可以弯，但 FK 出来的末端位置要贴着 P(t)。

2. 为什么不用匀速突起突停？

若直接令 s=t/T，速度在起点从 0 瞬间跳到常数，终点又瞬间归零。第一版要使用五次时间律：

u=t/T,\qquad s(u)=10u^3-15u^4+6u^5\dot{s}(0)=\dot{s}(1)=0,\qquad \ddot{s}(0)=\ddot{s}(1)=0

它并不改变几何路径，只决定沿同一条路径“什么时候走到哪里”。这正是路径与时间参数化的区别。

3. 拖动时间，观察当前位置、速度和加速度

演示路径

A=(0.50, 0.00, 0.65)，B=(0.40, 0.30, 0.75)。真实项目必须先用 ROS2-04/05 扫描整条路径，确认每一点都有受限合法解。

蓝虚线：几何路径 A→B；绿点：当前 P(t)。紫线：五次时间律 s(u)，并不是空间轨迹本身。

4. 生成器与 IK 的职责边界

def quintic_s(u):
    # 调用者保证 0 <= u <= 1
    return 10*u**3 - 15*u**4 + 6*u**5

def cartesian_line(start, end, duration, dt=0.02):
    steps = round(duration / dt)
    for k in range(steps + 1):
        t = min(k * dt, duration)
        s = quintic_s(t / duration)
        target = tuple(a + s * (b - a) for a, b in zip(start, end))
        yield t, target

# 在 ROS 节点中：
# 1) target 来自 cartesian_line
# 2) candidates = solve_position_ik(*target)
# 3) selected = select_continuous_solution(candidates, q_prev)
# 4) 若 selected 为空：停止本段，并报告 t 与 target
# 5) 若存在：发布 selected q 给数字孪生，并更新 q_prev

生成器不知道关节限位；IK 也不知道路径时间。二者之间只交接 target 和 selected q，这样才能准确指出路径在哪一帧失败。

5. 运行前必须做整段预扫描

检查为什么不能省失败时正确处理
逐点 IKA、B 都有解不代表中间每一点都有解或在限位内。不启动该段；缩短路径、换姿态或重设目标。
连续选支每一帧独立求解会让双解随机切换。用 ROS2-05 的 q_prev 代价选择。
FK 位置误差目标点和实际关节 FK 必须对照。记录最大误差；异常时回查 IK/URDF 约定。
速度、加速度限值五次时间律不自动保证每个关节都不过速。先拉长 T；真实控制阶段再由控制器限速。

本篇结束时的闭环

  • 你能解释：末端直线来自 P(t)，而不是来自某条 q(t)。
  • 你有一条从 A 到 B 的目标点列，每一点都必须经连续 IK 才能进入数字孪生。
