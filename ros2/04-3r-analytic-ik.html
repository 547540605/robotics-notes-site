ROS 2 工程实战 04：3R 单点解析逆运动学

把“末端想去哪里”翻译成“每个关节该转多少”。本篇只完成一个单点的闭环，不抢跑去讲轨迹、MoveIt 或真实设备控制。

先说工程痛点：为什么不能继续给三个关节写正弦波？

ROS2-03 中，我们能直接写 q1,q2,q3，机械臂就会在 RViz 中活动。但工位任务给出的从来不是“第 2 关节转 0.42 rad”，而是“让末端到这个工位坐标”。若不能把目标位置反解为关节角，后续的直线、视觉定位和路径规划都无从谈起。

① 读模型d、L1、L2 与零位
② 压平面(x,y,z) → (r,h)
③ 求双解肘上 / 肘下
④ 过限位筛出可执行解
⑤ FK 回代确认算对
本篇边界：当前 3R 只有三个自由度，因此仅规定 tool0 的位置 (x,y,z)。它不能同时规定工具完整姿态；六轴的 Pose 目标与姿态约束会在 ROS2-11、12 处理。

1. 先以 URDF 为准：这台 3R 到底是什么结构？

关节与连杆真值

  • joint1：绕 +Z 回转，范围 [-3.14, 3.14] rad；
  • joint2：绕局部 +Y 俯仰，范围 [-1.57, 1.57] rad；
  • joint3：绕局部 +Y 俯仰，范围 [-2.00, 2.00] rad；
  • 肩关节高度 d=0.05+0.20=0.25 m；
  • 大臂 L1=0.50 m，小臂 L2=0.40 m。

零位的关键直觉

当 q2=q3=0 时，两根杆都沿当前坐标系的 +Z 指向上方，而不是教材中常见的 +X 向右。因此我们稍后把二维平面坐标写作横向距离 r 与竖直高度 h。

这只是坐标约定不同；余弦定理本身没有变。

2. 从三维目标压到已经学过的二维两连杆问题

给定的目标始终在 base_link 下：P=(x,y,z)。腰部先转向目标的 XY 方位，肩和肘只需要在包含目标的竖直平面里解决两连杆问题。

\[r=\sqrt{x^2+y^2},\qquad h=z-d,\qquad q_1=\operatorname{atan2}(y,x)\]
这里的两个“高度”别混：z 是目标相对 base_link 的绝对高度；h 是目标相对肩关节的高度。只有减去 d 后，才能直接把 (r,h) 交给两连杆几何。

3. 先判可达，再碰反三角函数

几何可达环

\[|L_1-L_2|\le \sqrt{r^2+h^2}\le L_1+L_2\]

这是两根固定长度连杆能否拼出目标三角形的条件。条件不成立时，IK 没有解；不是调参数可以补救的。

几何可达 ≠ 可执行

即使三角形能拼出来，得到的 q2,q3 仍可能超过 URDF 的关节限位。因此我们会依次经过：几何可达 → 两支候选解 → 限位筛选 → 连续选择。连续选择放到 ROS2-05，本篇只列出候选。

4. 用余弦定理求肘角，再求肩角

在 (r,h) 平面，零位沿竖直 +Z。因此角度表达为：

\[c_3=\frac{r^2+h^2-L_1^2-L_2^2}{2L_1L_2},\qquad q_3=\pm\arccos(c_3)\] \[q_2=\operatorname{atan2}(r,h)-\operatorname{atan2}(L_2\sin q_3,\ L_1+L_2\cos q_3)\]

正、负两支 q3 分别对应两种肘部构型。别急着给它们固定叫“肘上/肘下”；在不同坐标约定和观察视角下名称容易反。代码只需可靠地区分 q3>0 与 q3<0。

5. 动手算一个点：先看两支候选，再看限位

目标点（单位：m）

默认点 (0.50,0.00,0.65) 位于安全工作区，用于展示一支候选可能被限位筛掉。

若目标在腰部 Z 轴上，方位角本来就不唯一；本篇会明确报告，而不是编造 q1。

6. FK 回代：不是多余步骤，而是你的闭环证明

任何候选角都必须重新带回当前 URDF 的正运动学。当前模型的 tool0 位置为：

\[\rho=L_1\sin q_2+L_2\sin(q_2+q_3)\] \[x=\rho\cos q_1,\quad y=\rho\sin q_1,\quad z=d+L_1\cos q_2+L_2\cos(q_2+q_3)\]
读法：先在肩部平面算出横向伸出量 ρ 和高度 z，再由 q1 将 ρ 旋转到全局 X-Y 平面。若回代位置与目标不同，不要继续做轨迹；先查零位方向、关节轴、连杆长度和角度单位。

7. 将公式放进 ROS 包：先保持它是纯函数

第一版求解器不继承 Node、不发布话题、不读取 RViz。纯函数让输入、输出和错误边界都可看清；ROS 节点只负责在下一步调用它。

# my_arm_motion/kinematics_3r.py
import math

D, L1, L2 = 0.25, 0.50, 0.40
Q2_LIMIT = (-1.57, 1.57)
Q3_LIMIT = (-2.00, 2.00)

def forward_position(q1, q2, q3):
    rho = L1 * math.sin(q2) + L2 * math.sin(q2 + q3)
    return (
        rho * math.cos(q1),
        rho * math.sin(q1),
        D + L1 * math.cos(q2) + L2 * math.cos(q2 + q3),
    )

def solve_position_ik(x, y, z, eps=1e-9):
    r = math.hypot(x, y)
    h = z - D
    distance = math.hypot(r, h)
    if distance < abs(L1 - L2) - eps or distance > L1 + L2 + eps:
        return {"reachable": False, "reason": "geometrically unreachable", "candidates": []}
    if r < eps:
        return {"reachable": False, "reason": "base yaw is undefined at r=0", "candidates": []}

    q1 = math.atan2(y, x)
    c3 = max(-1.0, min(1.0, (r*r + h*h - L1*L1 - L2*L2) / (2*L1*L2)))
    candidates = []
    for q3 in (math.acos(c3), -math.acos(c3)):
        q2 = math.atan2(r, h) - math.atan2(L2*math.sin(q3), L1 + L2*math.cos(q3))
        within_limits = Q2_LIMIT[0] <= q2 <= Q2_LIMIT[1] and Q3_LIMIT[0] <= q3 <= Q3_LIMIT[1]
        candidates.append({"q": (q1, q2, q3), "within_limits": within_limits})
    return {"reachable": True, "reason": None, "candidates": candidates}

ROS2-05 才会为候选加上“离上一帧最近”的连续选择规则。当前函数故意不替你偷偷选支。

8. 常见失败，不要靠猜

你看到的现象最可能的原因先做什么
acos 报 domain error目标超工作空间；或浮点误差使边界值略大于 1先打印距离与可达范围；只允许对极小数值误差 clamp。
两支几何解都存在，但 RViz 姿态不对将杆长、关节轴或零位方向按教材模型写错给定一组已知 q，先用 FK 对照 tf2_echo base_link tool0。
几何解存在却被全部淘汰目标需超过 joint2/joint3 限位报告“受限不可达”，不将角度硬裁剪到边界。
目标正好在 base Z 轴上atan2(0,0) 没有物理方位保持上一帧腰部角，或要求调用者给定偏好角；不要当普通点处理。

这一讲结束时，你应该带走什么？

  • IK 的输入是目标位置，输出是候选关节角，不是唯一答案。
  • 先压到 r-h 平面，才复用你已经学过的二维两连杆几何。
  • 几何可达、关节限位合法、FK 回代正确，是三道不同的门。
