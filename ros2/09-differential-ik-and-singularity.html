ROS 2 工程实战 09：微分 IK、DLS 与奇异位形规避

把“想让末端现在往哪儿走、多快走”转换成关节角速度；当这种转换不可靠时，优先保护关节，不假装还能精确跟随。

工程痛点：同一个末端速度请求，为什么关节会突然飞车？

ROS2-08 给出了 v=J(q)q_dot。若 J 可逆，形式上能写 q_dot=J⁻¹v_des。但接近奇异位形时，J 的某个方向几乎失去运动能力；为了挤出一个有限的末端速度，普通逆会要求无限大的关节速度。这不是控制器调得不好，而是当前姿态的几何退化。

1. 先区分三件事

微分 IK

输入期望末端速度，输出关节速度。它是局部瞬时关系，不等同于 ROS2-04 的位置 IK。

奇异位形

Jacobian 降秩，某些末端方向无法由有限关节速度产生。它是运动学问题，不是障碍物。

碰撞规避

关心机器人与环境几何体是否相交；后续由 MoveIt Planning Scene 处理，不能拿 DLS 代替。

降级策略

接近奇异时允许末端速度存在误差，换取关节速度有限、可预测和安全。

2. 先对齐符号与变量含义：普通逆 vs 阻尼最小二乘（DLS）

在写速度逆解公式前，先明确每一个矩阵、向量和标量参数的含义、维度与单位：

符号物理含义类型 / 维度坐标系与单位
\(\boldsymbol{v}_{\text{des}} = [v_{x,\text{des}}, v_{y,\text{des}}, v_{z,\text{des}}]^T\)期望末端线速度向量：上层任务希望末端 tool0 此刻在 base_link 下运动的三维线速度（已知输入）\(3\times 1\) 列向量base_link，\(\text{m/s}\)
\(\dot{\boldsymbol{q}} = [\dot q_1, \dot q_2, \dot q_3]^T\)待求的三轴关节角速度指令：为了产生期望末端速度，三个关节此刻分别需要转多快（求解输出）\(3\times 1\) 列向量关节空间，\(\text{rad/s}\)
\(\boldsymbol{J} = \boldsymbol{J}_p(\boldsymbol{q})\)当前姿态 \(\boldsymbol{q}\) 下的 \(3\times 3\) 位置雅可比矩阵（由 ROS2-08 算出）；\(\boldsymbol{J}^T\) 为其转置矩阵\(3\times 3\) 矩阵base_link，\(\text{m/rad}\)
\(\boldsymbol{I}\)\(3\times 3\) 单位矩阵：主对角线元素全为 \(1\)、其余元素全为 \(0\) 的方阵\(3\times 3\) 矩阵无量纲
\(\lambda \ge 0\)阻尼系数（Damping Factor）：在 \(\boldsymbol{J}\boldsymbol{J}^T\) 主对角线上加入的正则化阻尼项 \(\lambda^2\)，防止矩阵在奇异位形附近不可逆非负标量单位 \(\text{m/rad}\)
\(\sigma_{\min}(\boldsymbol{J})\)雅可比矩阵 \(\boldsymbol{J}\) 的最小奇异值：衡量当前姿态离奇异位形有多近的数值指标（\(\sigma_{\min}\to 0\) 表示进入奇异区）非负标量单位 \(\text{m/rad}\)

当机械臂远离奇异位形、\(\boldsymbol{J}\) 可逆且良态时，直接对 \(\boldsymbol{v}_{\text{des}} = \boldsymbol{J}\dot{\boldsymbol{q}}\) 左乘逆矩阵即可：

\[\dot{\boldsymbol{q}}=\boldsymbol{J}^{-1}\boldsymbol{v}_{\text{des}}\quad(\text{仅在 }\boldsymbol{J}\text{ 良态且 }\sigma_{\min}\text{ 足够大时可用})\]

一旦接近奇异位形（例如大小臂完全伸直 \(q_3=0\)），\(\boldsymbol{J}\) 近似不可逆，\(\boldsymbol{J}^{-1}\) 会算出趋近无穷大的关节速度。工程上改用阻尼最小二乘（Damped Least Squares, DLS），它等价于同时最小化“末端速度跟踪误差 \(\|\boldsymbol{J}\dot{\boldsymbol{q}}-\boldsymbol{v}_{\text{des}}\|^2\)”和“关节速度代价 \(\lambda^2\|\dot{\boldsymbol{q}}\|^2\)”：

\[\dot{\boldsymbol{q}}=\boldsymbol{J}^T\left(\boldsymbol{J}\boldsymbol{J}^T+\lambda^2\boldsymbol{I}\right)^{-1}\boldsymbol{v}_{\text{des}}\]
\(\lambda\) 的物理意义：当 \(\lambda=0\) 时，DLS 退化为普通求逆；当接近奇异位形、\(\lambda\) 增大时，\(\lambda^2\boldsymbol{I}\) 保证了括号内的矩阵永远可逆且良态——它不再偏执于“末端速度必须一丝不差”，而是用一点点末端速度偏差，换取关节角速度 \(\dot{\boldsymbol{q}}\) 平稳受控、绝不爆速。

3. 实现顺序：先有监控，再有 DLS

def differential_ik(J, v_des, sigma_min, velocity_limits):
    """概念骨架：末端期望线速度→限幅关节速度；不是可直接运行的节点。

    返回 (q_dot_limited, damping)：三轴关节速度(rad/s)和本周期阻尼值。
    """
    # J 是当前位置的 3×3 位置 Jacobian；v_des 是 base_link 下速度(m/s)。
    # sigma_min 为 J 的最小奇异值；velocity_limits 是逐轴 rad/s 上限。
    # SIGMA_SAFE、LAMBDA_*、I、solve、clip_each_joint 需由具体实现定义。
    # 1) 根据最小奇异值选择阻尼；阈值需由设备速度能力和任务误差决定
    if sigma_min >= SIGMA_SAFE:
        damping = LAMBDA_MIN
    else:
        ratio = 1.0 - max(0.0, sigma_min) / SIGMA_SAFE
        damping = LAMBDA_MIN + ratio * (LAMBDA_MAX - LAMBDA_MIN)

    # 2) 解 DLS；真实实现用稳定线性求解器，不显式求矩阵 inverse
    # 解线性方程 A·y=v_des，再左乘 Jᵀ；避免显式计算 A⁻¹。
    q_dot = J.T @ solve(J @ J.T + damping*damping*I, v_des)

    # 3) 对每个关节分别按 rad/s 上限裁剪；裁剪后末端速度不再等于 v_des。
    q_dot_limited = clip_each_joint(q_dot, velocity_limits)
    return q_dot_limited, damping

# 每一控制周期还应记录：sigma_min、damping、||v_des-v_actual||、是否触发限速

4. 如何验证“保护生效”？

观察项远离奇异位形接近奇异位形
最小奇异值 σmin明显大于安全阈值趋近 0，触发预警
普通逆关节速度有限且可执行快速放大，可能超限
DLS 关节速度接近普通逆结果保持有限，但末端速度允许偏差
上层动作按正常速度继续降速、重规划或退出危险姿态
需要显示的诊断量：在 RViz/终端面板显示 `σmin`、阻尼 λ、每关节 q_dot、期望与实际末端速度误差。只有看到这些量，才知道 DLS 是在正常工作还是在悄悄掩盖错误。

5. 本篇不替你做的事情

  • 不解决碰撞，也不替代 MoveIt 的规划场景；
  • 不处理完整六维姿态，只处理当前 3R 的位置 Jacobian；
  • 不直接向真实设备下发速度命令；真实控制模式、限速与急停要由厂商驱动和 ros2_control 共同约束。
