ROS 2 工程实战 18：动力学、轨迹约束与柔顺控制

运动学解决“怎样到”；动力学解决“以这个速度和加速度运动，需要多大力矩”；柔顺控制解决“接触或受外力时，不要把位置误差硬顶到底”。三者有关，但不是同一个模块。

先按工程顺序建立能力，而不是直接往真机写 torque

① 运动学q → TCP 位姿/速度
② 时间参数化路径 → q、q̇、q̈、jerk
③ 逆动力学状态 → 需要的 τ
④ 前馈/补偿重力、摩擦、载荷
⑤ 柔顺接触力 ↔ 位移/速度修正

本篇首先在可计算模型和仿真/数据回放里建立这些概念。真机 torque 模式、力传感器、驱动器带宽和安全约束尚未确定前，不发布可直接驱动物理设备的控制指令。

1. 一条完整动力学方程，先读懂每一项在问什么

τ = M(q)q̈ + C(q,q̇)q̇ + g(q) + τfriction(q̇) + τexternal-comp
项含义最直观的实验现象
M(q)q̈惯性项：要改变速度就需要力矩；质量分布和姿态都会影响同样的加速度，伸直手臂比收回手臂更“费力”
C(q,q̇)q̇速度耦合项：关节一起运动时彼此影响高速联动时，单纯静态重力补偿不够
g(q)重力项：静止悬停也要抵消重力低速时手臂在不同姿态有不同下垂趋势
τ_friction摩擦、粘滞、库仑摩擦等未理想化阻力低速换向时误差、滞回、爬行
τ_external-comp外力/工具/接触相关项，符号取决于模型约定触碰工件时，实际力矩偏离空载预测
符号不要背死：有的教材把外部 wrench 映射项移到等式左边，有的把摩擦合并到 h(q,q̇)。关键是明确“τ 是电机施加给机器人，还是环境施加给机器人”的约定，并用同一约定贯穿模型、日志和控制器。

2. 轨迹不只是位置列表：控制器真正面对 q、q̇、q̈ 与 jerk

若只给若干位置点和时间点，控制器可能通过插值补齐速度/加速度，但这不等于你已经验证了电机、减速机、结构和工艺允许这些变化。可执行轨迹至少需要考虑四类边界：

位置 / 速度 / 加速度

q_min ≤ q ≤ q_max、|q̇| ≤ q̇_max、|q̈| ≤ q̈_max 是最基础的几何与驱动边界。速度缩放不能修复一条本身撞关节限位的路径。

jerk（加加速度）

j = d q̈ / dt 约束加速度变化是否突兀。jerk 过大常带来机械冲击、振动、跟踪误差和工艺不稳定；它是“到得快”与“到得稳”之间的重要分界。

# 对一条关节路径 q(s)，时间律 s(t) 决定它“怎么走”：
q_dot  = dq/ds * s_dot
q_ddot = d²q/ds² * s_dot² + dq/ds * s_ddot

# 所以同一条空间路径，换一条时间律，峰值速度、加速度、力矩都可能不同。
# ROS2-06 的五次时间律解决端点平滑；工业轨迹还需检查全程各关节约束。

3. 逆动力学与动力学仿真：输入/输出别倒置

问题已知求什么用途
逆动力学（RNEA）q、q̇、q̈、载荷/重力模型τ轨迹可行性、重力前馈、扭矩预测
正动力学q、q̇、τq̈仿真、研究外力或控制律下会如何运动
参数辨识记录的状态、力矩/电流、激励轨迹质量、质心、摩擦等参数让模型逐步贴近真实设备

Craig 的 Newton–Euler 外推/内推正是逆动力学的递推思路：先计算每节的速度、加速度和质心加速度，再从末端向基座回传力与力矩。ROS 中的控制器接口不能替代这套模型；它只定义模型计算出的命令怎样被交给硬件。

4. 前馈与 PID：不是二选一

τ_command = τ_feedforward(q_ref, q_dot_ref, q_ddot_ref)
          + Kp · (q_ref - q)
          + Kd · (q_dot_ref - q_dot)

# feedforward：根据模型预先抵消可预测负担（例如重力、期望加速）。
# feedback：根据实际误差修正模型不准、扰动和未建模因素。
# 真机是否允许外部 torque command，取决于厂商控制模式和安全设计。
误区：“有了重力补偿就不需要 PID”不对；“PID 跟得上就不用动力学”也不对。低速、负载变化或高精度工艺时，前馈可以显著减小反馈必须承担的误差，但它的收益受参数质量、传感器和控制带宽限制。

5. 阻抗与导纳：必须从输入、输出判断

阻抗（Impedance）

输入：位置/速度误差。输出：期望力/力矩或等效控制作用。

Fcmd = K(xd-x) + D(vd-v)

像一个可调虚拟弹簧-阻尼器：偏得越多，推回去越强。

导纳（Admittance）

输入：测得外力/力矩。输出：位置或速度修正。

MΔẍ + DΔẋ + KΔx = Fext

外力越大，参考轨迹允许偏移越多；常用于外层生成柔顺位置命令。

接触控制的前置条件：必须知道外力从何而来（六维力传感器、关节力矩估计或驱动器电流估计）、它的坐标系与滤波延迟；还要有速度/力/位移限值和机械/电气安全策略。没有这些，谈“柔顺”只是控制方程，不是安全功能。

6. 跟做顺序：从日志/仿真到真机

A. 先做单关节：用一条平滑 q(t) 画出 q、q̇、q̈、jerk；找出速度与加速度峰值发生在哪里。
B. 再做两连杆：固定一组质量/质心参数，计算不同姿态下的重力项；验证手臂伸出与收回的差异。
C. 加入完整三维/六轴模型：用 RNEA 或成熟动力学库计算给定轨迹的 τ；检查是否超过已知电机/关节边界。
D. 参数辨识先留验证集：用一批激励轨迹拟合，另一批轨迹比较预测与记录残差；不能只报告拟合内误差。
E. 在仿真中做单轴导纳：给定一个受限的外力输入，检查输出位移、速度和停止边界。
F. 真机最后进入：先确认厂商是否提供批准的 torque/force mode、力传感器和安全机制；从低速、单轴、空载或受控柔性介质开始。
本篇完成判据：你能写出并解释动力学方程的每一项；能说明同一空间路径为何会因时间律不同而产生不同力矩；能不看标题而区分阻抗与导纳；也能明确哪些实验只能等真实设备和安全条件满足后再进行。
