ROS 2 工程实战 08：3R 位置 Jacobian

位置 IK 问“要到某点，关节角是多少”；Jacobian 问“此刻每个关节转一点，末端会瞬时往哪儿走”。

工程痛点：位置路径到了速度层，不能再靠猜

ROS2-06 是逐点求位置 IK。若想做速度跟随、在线微调或在靠近奇异姿态时保护关节，就必须知道关节角速度与末端线速度之间的局部映射。Jacobian 是该映射，不是新的“黑盒算法”。

1. 从已有 3R 正运动学开始

沿用 ROS2-04 的符号：

\[\rho=L_1\sin q_2+L_2\sin(q_2+q_3)\]\[p(q)=\begin{bmatrix}\rho\cos q_1\\\rho\sin q_1\\d+L_1\cos q_2+L_2\cos(q_2+q_3)\end{bmatrix}\]

Jacobian 的定义只是将这个位置向量分别对三个关节角求偏导：

\[v=\dot p=J_p(q)\dot q,\qquad J_p=\begin{bmatrix}\frac{\partial p}{\partial q_1}&\frac{\partial p}{\partial q_2}&\frac{\partial p}{\partial q_3}\end{bmatrix}\]

2. 三列不是抽象数字：每一列都是一个关节的速度贡献

第 1 列：腰部 q1

腰部绕 Z 转，末端在 XY 平面做切向运动，因此 Z 分量为 0：

\[J_1=[-\rho\sin q_1,\ \rho\cos q_1,\ 0]^T\]

第 2 列：肩部 q2

肩转动改变整条两连杆的伸出量与高度：

\[J_2=[c_2\cos q_1,\ c_2\sin q_1,\ -\rho]^T\]

其中 $c_2=L_1\cos q_2+L_2\cos(q_2+q_3)$。

第 3 列：肘部 q3

肘只影响第二根杆：

\[J_3=[L_2\cos(q_2+q_3)\cos q_1,\ L_2\cos(q_2+q_3)\sin q_1,\ -L_2\sin(q_2+q_3)]^T\]

三列合起来

给定 q_dot=[q1_dot,q2_dot,q3_dot]，末端速度不是任何单列，而是：

\[v=J_1\dot q_1+J_2\dot q_2+J_3\dot q_3\]

3. 用数值差分核对解析式

这一页最重要的工程动作不是背矩阵，而是拿 FK 检查它。对一个很小的 Δq：

\[J_p(q)\Delta q\approx p(q+\Delta q)-p(q)\]
def numerical_check(q, dq, eps=1e-6):
    # fk 和 jacobian_position 都来自同一份 URDF 约定
    predicted = jacobian_position(q) @ dq
    actual = forward_position(*(q + eps * dq)) - forward_position(*q)
    actual /= eps
    return predicted, actual, norm(predicted - actual)

# 只用很小的扰动。扰动太大时，右边是真实曲线位移，
# 左边只是一阶切线近似，两者出现差异是正常的。

4. 这一步在 ROS 图里放在哪里？

输入

  • 当前关节状态 q，来自状态链；
  • 关节角速度 q_dot，来自规划器、操纵器或控制器；
  • URDF 参数和关节轴约定。

输出

  • 末端瞬时线速度 v；
  • 每个关节的独立贡献 J_i qdot_i；
  • 接近奇异时的条件指标（下一篇处理）。
不要混淆：robot_state_publisher 用关节位置做 FK 并发布 TF；它不会替你自动发布这个 Jacobian。Jacobian 是你的运动学/控制节点需要显式计算和使用的量。

5. 本篇排错表

现象通常意味着什么
解析 J 与数值差分完全不符FK、关节轴、正负号或 q2/q3 的零位约定至少有一处不一致。
只给 q1 速度，J1 的 Z 分量却不为 0当前 URDF 的 q1 并非绕 base Z，或代码错误地使用了未旋转的局部轴。
同一 q_dot 在不同姿态得到不同 v正常。Jacobian 是依赖当前姿态 q 的局部映射。

  • 你知道 Jacobian 每一列对应一个关节的瞬时末端速度贡献。
  • 你能用 FK 数值差分核对解析 Jacobian，而不是只相信公式。
