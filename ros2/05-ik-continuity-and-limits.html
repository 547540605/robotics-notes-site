ROS 2 工程实战 05：IK 连续选支与关节限位

单点 IK 已经能给出两支候选解。本篇解决真正开始走路径时最危险的现象：目标只挪了一点，肘部却突然翻到另一侧。

承接 04：从单点候选到逐点选择

04 已完成几何求解、候选与 FK 回代；12a 解释了两支解、零位和投影。本篇不改那些公式，只增加上一帧姿态和选支规则。几何上有两支，不代表两支都满足设备限位。

本篇原则：检查上一帧与所有候选的关节限位，再选择离上一帧最近的合法候选。它是保持相邻构型的启发式，不是完整的路径规划或执行许可。

1. 连续选支的输入与输出

输入

  • 当前目标点 P(k)；
  • ROS2-04 返回的两支 IK 候选；
  • 上一帧真正已选用的 q_prev；
  • URDF 关节限位。

输出

  • 几何候选是否存在；
  • 每一支是否满足限位；
  • 每一支距 q_prev 的代价；
  • 唯一选中的 q_selected，或明确失败原因。
顺序不能反：先做几何可达性，再筛关节限位，最后才比较“离上一帧近不近”。超过限位的候选不允许因为距离更近而被选中。

仍用 04 的同一台教学模型

d=0.25 m，L1=0.50 m，L2=0.40 m。三个关节都有角度上、下限：

  • joint1 / q1：[-3.14, 3.14] rad，约 ±179.91°；
  • joint2 / q2：[-1.57, 1.57] rad，约 ±89.95°；
  • joint3 / q3：[-2.00, 2.00] rad，约 ±114.59°。

04 的候选标记原先只检查 q2、q3；本篇重新核对三个关节，不能仅信任旧的 within_limits 字段。1.57 rad 不等于 90°，限位按未舍入的弧度值比较。

2. 从当前角到候选角，关节要改变多少？

上一帧关节角 q_prev 是现在，IK 给出的 q_candidate 是目标。本模型有关节限位，只需计算实际角度坐标的变化量；先看 +179° 到 −179° 这个容易看错的例子：

为看清挡块，图中放大了靠近 ±180° 的间隙；358° 以标注为准，不按图上线段量角。

为什么用“候选角 − 上一帧角”？

q_prev 是关节现在的角度；q_candidate 是 IK 算出、希望它到达的角度；Δq 是从现在到目标要改变多少角，带正负号。先写“现在 + 变化量 = 目标”，即 q_prev + Δq = q_candidate；把 q_prev 移到右边，就得到下面的减法。这与位置的“终点坐标 − 起点坐标 = 位移”是一回事。

图中代入：Δq = −179° − (+179°) = −358°。负号表示沿角度减小方向走；|Δq| = 358° 表示路程大小。比较 IK 候选时，三个关节都按这个方法算变化量。

Δqᵢ=qᵢ,candidate−qᵢ,prev
本节只需要这一个公式。它告诉我们候选解相对上一帧差多少，供后面的“选最近合法解”使用。算出差值不等于整段运动已经安全；仍须检查路径中的限位和其他约束。

3. 选择规则：所有关节一起比较，而不是只看肘角

这一步到底要干什么？

04 已经为同一个末端目标点算出两组关节角：一组把肘部放在一侧，另一组放在另一侧。末端都能到，机械臂姿态却不同。现在末端沿路径挪到下一点时，不能每帧随意选一组，否则肘部可能突然翻转。05 的任务就是：先排除超出关节限位的解，再从剩下的解中挑一个与上一帧关节角最接近的。

所谓“接近”不是末端位置接近——两支末端本来就在同一点——而是 q1、q2、q3 三个关节各自要改变多少。下面只用页面交互区的默认数字做一次完整演算。

把默认输入逐项代进去

上一帧 q_prev=(0°, 12°, 77°)，目标 (x,y,z)=(0.50,0,0.75) m。04 的 IK 为该目标算出两支；它们都满足三轴限位，所以这次才能比较“哪支更近”。

同一目标的解候选关节角 (q1,q2,q3)减去上一帧后的角度变化代价（rad²）
紫色 A(0°, 11.552°, +76.997°)(0°, −0.448°, −0.003°)约 0.000061
绿色 B(0°, 78.448°, −76.997°)(0°, +66.448°, −153.997°)约 8.5690

紫色只让 q2、q3 微调；绿色要让肩部和肘部大幅转动。代价越小，表示这三个关节合起来改得越少，所以本帧选紫色 A。注意这不是拿两个候选彼此相减，而是每个候选分别减去同一个上一帧。

公式只是把上表“分别求差、平方、加起来”的操作缩写成一行：i=1,2,3 分别代表三个关节；平方让正转、反转都计入改变量，并让大跳变更贵；Σ 表示三项相加。本课先令 w1=w2=w3=1。以后即使调整权重，也必须让三项都大于 0；设成 0 会让那根关节的跳变完全不计入代价。

cost(q)=Σᵢ wᵢ(qᵢ−qprev,ᵢ)²

表里用度数方便读，代价按代码一样先转成弧度再平方，所以单位是 rad²。若直接用度数平方，这两支的排序也不变，但数值不会是表中的 0.000061 与 8.5690。最近候选只是一条选支规则，不等于已经验证整条运动安全。

先看限位检查的一个具体例子

给 violations() 一组角度 q=(0, 1.70, 0.50) rad：第 1 轴的 0 落在 [-3.14, 3.14]，第 2 轴的 1.70 超过上限 1.57，第 3 轴的 0.50 落在 [-2.00, 2.00]。因此只记录第 2 轴，返回 [{"joint": 2, "value": 1.70, "allowed": (-1.57, 1.57)}]。若三轴都没超限，就返回空列表 []。

下方改用普通循环：i=0,1,2 是 Python 下标，对应第 1、2、3 关节；v 是该轴当前角度，lo/hi 是该轴下限/上限。只有 v<lo 或 v>hi 才把错误写入列表。

# 追加到 ~/ros2_ws/src/my_arm_motion/my_arm_motion/kinematics_3r.py
# 放在 04 的 solve_position_ik() 定义结束之后；保留 04 原有的两个函数。
import math  # 若文件顶部已有 import math，不重复添加。

# 顺序固定为 (joint1, joint2, joint3)；上下限来自 02 的 URDF，单位 rad。
JOINT_LIMITS = ((-3.14, 3.14), (-1.57, 1.57), (-2.0, 2.0))

def select_nearest_valid_solution(candidates, q_prev, weights=(1.0, 1.0, 1.0)):
    """先筛三轴限位，再选离上一帧最近的一支；不检查整条轨迹。

    candidates: 传入 04 的结果["candidates"]，不是整个结果字典；
                每项至少有 {"q": (q1, q2, q3)}，角度单位 rad。
    q_prev:    上一帧真正选用的 (q1, q2, q3)，单位 rad；不是上一帧的目标位置。
    weights:   三轴代价权重；默认都为 1，且每项必须有限、大于 0。
    返回:      selected 是选中的候选字典，失败时为 None；
               candidates 是已评估候选（上一帧非法时为空），每支附限位和 cost；
               reason 说明失败原因，trajectory_checked 始终为 False。
    """
    # 本模型三个关节都是有界 revolute；先拒绝长度不对或 NaN/无穷角度。
    if len(q_prev) != 3 or not all(math.isfinite(v) for v in q_prev):
        raise ValueError("q_prev must contain three finite angles")
    # 权重无量纲；每轴都须参与比较，0 会让该轴的跳变完全不计入代价。
    # cost 是加权角度差平方和，角度用 rad，结果单位 rad²。
    if len(weights) != 3 or not all(math.isfinite(w) and w > 0 for w in weights):
        raise ValueError("weights must contain three finite positive numbers")

    def violations(q):
        """输入三个关节角(rad)，返回超限轴的信息；[] 表示全部合法。"""
        errors = []
        for i in range(3):  # i=0/1/2 分别检查 joint1/joint2/joint3。
            v = q[i]             # 取出第 i 轴当前角度(rad)。
            lo, hi = JOINT_LIMITS[i]  # 取出同一轴的下限和上限(rad)。
            if v < lo or v > hi:
                # 只有超限才记录；给用户看的轴号从 1 开始，所以 i+1。
                errors.append({"joint": i + 1, "value": v, "allowed": (lo, hi)})
        return errors

    # 上一帧若已超限，不能以它为“连续性”基准；此时还没有评估候选。
    prev_errors = violations(q_prev)
    if prev_errors:
        return {"selected": None, "reason": "q_prev outside joint limits",
                "violations": prev_errors, "candidates": [],
                "trajectory_checked": False}

    evaluated = []
    for candidate in candidates:
        # 04 每项是字典，q 字段才是 (q1,q2,q3)；旧 within_limits 只查过 2/3 轴。
        q = candidate["q"]
        if len(q) != 3 or not all(math.isfinite(v) for v in q):
            raise ValueError("each candidate must contain three finite angles")
        errors = violations(q)  # 重查全部三轴，不只信任 04 的旧标记。
        # errors=[] 表示没有超限项，布尔值为 False；有错误则不计算代价。
        # 非法候选的 cost=None：不让它因“看起来很近”而被选中。
        # zip 把同一轴的 (权重, 候选角, 上一帧角) 配到一起；逐轴平方后求和。
        cost = None if errors else sum(
            w * (v - last) ** 2 for w, v, last in zip(weights, q, q_prev)
        )
        # **candidate 保留 04 的 q 等原字段，再覆盖/补充本篇的检查结果。
        evaluated.append({**candidate, "within_limits": not errors,
                          "violations": errors, "cost": cost})

    # 没有合法候选就停下并报告，不裁剪角度，也不跳过该目标点。
    legal = [c for c in evaluated if c["within_limits"]]
    if not legal:
        return {"selected": None, "candidates": evaluated,
                "reason": "no candidate within joint limits",
                "trajectory_checked": False}
    # 只在合法候选里选 cost 最小者；同代价时 min 保留输入顺序。
    selected = min(legal, key=lambda c: c["cost"])
    # selected["q"] 才是下一帧关节角(rad)；调用者用它更新 q_prev。
    # trajectory_checked=False：只比较这一帧，尚未验证沿途速度、碰撞或奇异性。
    return {"selected": selected, "candidates": evaluated, "reason": None,
            "trajectory_checked": False}

这段函数只做“选择”，不重复推导 IK。几何、限位和连续性拆开，后续排错才能知道是哪一层出问题。

6. 工作空间边界要分成三层看

边界由什么决定失败时的含义
几何工作空间杆长 L1、L2 与肩部平面距离两根杆根本拼不出目标三角形。
受限工作空间joint1、joint2、joint3 的上下限几何上够得着，但当前设备不允许转到那个姿态。
连续可达工作空间上一帧构型、限位、完整路径与时间参数单个点有解，不代表从当前姿态能平滑到达；本篇最近候选法还没有验证这一层。
选支成功 ≠ 可以直接执行。还要检查相邻帧的关节跳变量、速度和加速度、奇异区、碰撞与控制器约束。没有候选或跳变太大时，应停下并报告或重新规划；不能强行换支、跳过路径点或把角度裁到限位。
