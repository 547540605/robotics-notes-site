ROS 2 工程实战 05：IK 连续选支与关节限位

单点 IK 已经能给出两支候选解。本篇解决真正开始走路径时最危险的现象：目标只挪了一点，肘部却突然翻到另一侧。

工程痛点：数学上都对，运动上却可能很糟

同一个目标位置通常对应两组合法关节角。若每一帧都“随便取第一组”，当候选排列、角度跨越 ±π 或限位状态改变时，控制输出就可能突然跳变。设备并不关心哪组解在纸上优雅；它只会执行你给它的关节目标。

本篇原则：先留下所有合法候选，再在其中选择离上一帧关节姿态最近的一支。

1. 连续选支的输入与输出

输入

  • 当前目标点 P(k)；
  • ROS2-04 返回的两支 IK 候选；
  • 上一帧真正已选用的 q_prev；
  • URDF 关节限位。

输出

  • 几何候选是否存在；
  • 每一支是否满足限位；
  • 每一支距 q_prev 的代价；
  • 唯一选中的 q_selected，或明确失败原因。
顺序不能反：先做几何可达性，再筛关节限位，最后才比较“离上一帧近不近”。超过限位的候选不允许因为距离更近而被选中。

2. 为什么直接相减会在 ±π 附近出错？

旋转关节的 +179° 和 -179° 实际只差 2°，但普通相减会得到 358°。比较两个转动角前，必须把差值折回 [-π,π]：

Δθ=atan2(sin(θ_candidate-θ_prev), cos(θ_candidate-θ_prev))
这条式子不是改目标角，也不是替机械臂多转一圈。它只用于计算“两个角在圆周上最短相隔多少”，从而避免选择器把临近姿态误判成远离姿态。

3. 选择规则：所有关节一起比较，而不是只看肘角

cost(q)=\sum_i w_i\,[wrap(q_i-q_{prev,i})]^2

默认可令所有权重 w_i=1。若某关节体积大、限位紧或运动代价高，后续可以提高它的权重；但第一版必须先把规则保持透明。

5. 放进求解器：返回“为什么选它”，而不只返回角度

def wrap_angle(delta):
    return math.atan2(math.sin(delta), math.cos(delta))

def select_continuous_solution(candidates, q_prev, weights=(1.0, 1.0, 1.0)):
    # candidates 已完成几何求解；每一项有 q 与 within_limits
    executable = [c for c in candidates if c["within_limits"]]
    if not executable:
        return {"selected": None, "reason": "no candidate within joint limits"}

    def cost(candidate):
        return sum(w * wrap_angle(q - q_last) ** 2
                   for w, q, q_last in zip(weights, candidate["q"], q_prev))

    scored = [{**c, "cost": cost(c)} for c in executable]
    selected = min(scored, key=lambda c: c["cost"])
    return {"selected": selected, "candidates": scored, "reason": None}

这段函数只做“选择”，不重复推导 IK。几何、限位和连续性拆开，后续排错才能知道是哪一层出问题。

6. 工作空间边界要分成三层看

边界由什么决定失败时的含义
几何工作空间杆长 L1、L2 与肩部平面距离两根杆根本拼不出目标三角形。
受限工作空间joint2、joint3 的上下限几何上够得着，但当前设备不允许转到那个姿态。
连续可达工作空间上一帧构型、限位、路径连续性单个点有解，不代表从当前姿态能平滑到达。
