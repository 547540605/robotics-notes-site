# 机器人学课程网站

这是独立机器人学项目中 `robotics-notes/` 目录的公开网页副本。课程入口是 [交互式学习目录](index.html)。

仅发布原项目中已跟踪的 HTML、JavaScript 和配套 Markdown；不发布简历、教材扫描页或 PDF。课程内容的维护来源仍是原项目，本仓库仅用于 GitHub Pages 展示。

当前课程内容同步到原项目提交 `4da7e1a`。机器人学 01 增加了教材坐标记号与 ROS 2 `PointStamped` 的对照；12a 空间 3R 联动课包含可点击的前置知识导航，ROS2-04 以它为基础讲当前 URDF 和工程求解。基础支撑现有带稳定锚点的线代术语速查页。后续课程首次使用未铺垫的专业术语时，先给一句解释，再链接到相应基础页的术语锚点；不要只在目录里放链接。更新课程时，应重新核对并同步允许公开的文件，再验证导航与交互页面。
