线代术语速查：为什么旋转矩阵的逆等于转置？

按“点积 → 单位正交 → 转置 → 正交矩阵 → 逆矩阵”的顺序读。课程里这些术语可直接跳到对应小节；读完用浏览器返回，继续原处学习。

点积单位正交基转置正交矩阵逆矩阵

1. 点积：怎样判断两根轴垂直？

两个向量对应分量相乘再相加，就是点积：$a\cdot b=a_xb_x+a_yb_y+a_zb_z$。它也等于 $\lVert a\rVert\lVert b\rVert\cos\theta$，所以对于非零向量，点积为 0 等价于夹角 $90^\circ$。

例如 $a=(1,0,0)$、$b=(0,1,0)$，有 $a\cdot b=1\times0+0\times1+0\times0=0$；它们互相垂直。$a\cdot a=\lVert a\rVert^2$，也能用点积检验长度。

2. 单位正交基：垂直还不够

“正交”只要求不同轴互相垂直；“单位正交”还要求每根轴长度为 1。机器人坐标系的三根单位轴 $r_1,r_2,r_3$ 满足：

$$r_i\cdot r_j=\begin{cases}1,&i=j\\0,&i\ne j\end{cases}$$
$(2,0)$ 与 $(0,3)$ 虽然垂直，但长度分别为 2 和 3，不是单位正交基；$(1,0)$ 与 $(0,1)$ 才是。

3. 转置：把行与列交换

矩阵转置记作 $A^T$。原矩阵第 $i$ 行第 $j$ 列的数，转置后放到第 $j$ 行第 $i$ 列：

$$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}\quad\Longrightarrow\quad A^T=\begin{bmatrix}1&3\\2&4\end{bmatrix}$$

转置只是重新排列元素；任意矩阵的转置不一定是它的逆。下面的条件满足时才可以这么做。

4. 正交矩阵：列轴的点积组成单位矩阵

把三根单位正交轴作为列排成 $R=[r_1\;r_2\;r_3]$。矩阵乘法告诉我们：$R^TR$ 的第 $i$ 行第 $j$ 列，恰好是 $r_i\cdot r_j$。由上一节的“对角为 1、其余为 0”，得到：

$$R^TR=\begin{bmatrix}r_1\cdot r_1&r_1\cdot r_2&r_1\cdot r_3\\r_2\cdot r_1&r_2\cdot r_2&r_2\cdot r_3\\r_3\cdot r_1&r_3\cdot r_2&r_3\cdot r_3\end{bmatrix}=I$$

满足 $R^TR=I$ 的方阵叫正交矩阵。旋转矩阵一定是正交矩阵，但正交矩阵还包括镜像反射；只有再满足 $\det R=+1$，才是三维的纯旋转矩阵。

判断“是不是旋转”：先查 $R^TR=I$，再查 $\det R=+1$。只查第一条会把反射也算进去。

5. 逆矩阵：把变换做回去

逆矩阵 $A^{-1}$ 的定义是 $A^{-1}A=AA^{-1}=I$：先做 $A$ 再做它的逆，结果不变。对上一节的方形正交矩阵，已经证明 $R^TR=I$，所以 $R^{-1}=R^T$。几何上，转过去后再转回来。

二维逆时针旋转 $90^\circ$：

$$R=\begin{bmatrix}0&-1\\1&0\end{bmatrix},\qquad R^T=\begin{bmatrix}0&1\\-1&0\end{bmatrix},\qquad R^TR=I$$

$(1,0)$ 经 $R$ 变为 $(0,1)$，再经 $R^T$ 回到 $(1,0)$。

在 笔记 01，用它把坐标从 A 系写回 B 系；在 笔记 02，用它推导齐次变换的逆。实际浮点计算有误差：若输入矩阵已经偏离正交条件，不能盲目把转置当逆。
