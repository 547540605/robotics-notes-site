笔记 38：CTC 的模型从哪里来？——动力学参数辨识与独立残差验证

37 已经展示：模型质量有偏差时，CTC 仍要靠反馈补救。工程上不能只说“把模型调准”，而要回答：记录了什么数据、哪些参数真的能从数据里区分、激励轨迹是否足够、拟合后的模型有没有在未见数据上变好。

辨识不是调一个神秘增益，而是闭合一条数据证据链

受控激励轨迹 + 同步的 q,q̇,q̈,τ → 回归模型 → 参数 θ̂ → 未参与拟合的数据残差 → 决定是否可用于前馈

若只在一段数据上把误差调小，可能只是记住了那段运动。真正有用的模型必须在不同姿态、速度、加速度或负载条件下仍能解释主要力矩趋势。

1. 先从单关节最小模型读懂“线性于参数”

τ = Iq̈ + αcos(q) + bq̇ + f_c tanh(q̇/v_ε) + ε

其中 α=mgr 是质量、质心和重力的组合，ε 包含噪声、未建模摩擦、传动柔性和时间不同步等残差。固定平滑速度 v_ε 后，可写成：

τ = Y(q,q̇,q̈)θ + ε,   θ=[I, α, b, f_c]ᵀ

为什么这很重要？

对固定采样数据，每一行 Y 都由测得的运动状态组成；未知的只有参数向量 θ。因此可用最小二乘、带正则化的回归或更完整的动力学辨识方法估计它。

“可辨识”不等于每个物理量都能单独拿到

从单关节重力项里常先看到的是 α=mgr，而非独立的 m 与 r。多连杆动力学也常使用“基参数”而非全部原始惯性参数。不要把数学上无法区分的量伪装成精确物理真值。

2. 数据采集最容易犯的四个错误

错误为什么会失败正确处理
只在一个静止姿态采样只能看到部分重力项，几乎看不到惯性与摩擦设计含位置、速度和加速度变化的受控激励。
用带噪位置直接差分两次q̈ 会放大编码器噪声，回归器被污染使用解析轨迹导数、合适滤波/观测器，并记录延迟。
拟合和验收用同一段数据误差小可能只是过拟合按时间段或轨迹类型分开 fit 与 validation。
换工具后继续沿用旧参数负载质量、质心、惯量改变记录 payload/TCP 版本，必要时重辨识或做负载参数更新。

4. 多连杆实际辨识：保留同一逻辑，增加规范性

模型层

τ = Y(q,q̇,q̈)θ_base + τ_f + ε

RNEA 或闭式动力学可产生回归项。参数向量应使用经过可辨识性处理的基参数；工具负载、质心和惯量需有明确版本。

数据层

轨迹要同时覆盖不同关节角、正反向速度、加减速和典型负载。记录 raw 状态、命令/测得力矩、时间戳、控制模式、温度和配置版本；任何滤波、延迟对齐都应可追溯。

与 35 的准确连接：CTC 中的 M̂、ĥ、ĝ 不是“拟合曲线就完事”，而是由参数 θ̂ 生成的模型项。只有在独立轨迹上的力矩残差和跟踪误差都得到改善，才有理由把新参数带回前馈控制。

5. 辨识完成的最低验收，不是“参数看起来合理”

  1. 数据覆盖可解释：能说明每段激励想分辨惯性、重力还是摩擦；没有只靠静态点拟合所有参数。
  2. 训练与验证分开：报告两边 RMS、峰值、残差随位置/速度/加速度的模式，而不只报一个总数。
  3. 残差仍可诊断：若误差集中在换向、加速度尖峰或特定姿态，明确标记可能的摩擦、柔性、同步或模型结构缺口。
  4. 控制收益单独评估：比较旧/新参数下的前馈力矩与跟踪，不把更高 PID 增益造成的改善误说成辨识成功。
最小二乘得到一组参数，就等于真实物理参数吗？

不等于。它是在给定模型、数据、噪声和约束下最能解释样本的一组估计。若激励不足、参数相关、时间不同步或模型缺项，估计可能不唯一或偏向补偿误差；因此必须保留置信度、条件数、残差和独立验证。

为什么要把库仑摩擦写成 tanh，而不是纯 sign？

sign 在零速度处不连续，数值优化和仿真容易不稳定。tanh 是一种平滑近似，便于教学和回归；真实摩擦还可能有静摩擦、Stribeck 效应、温度与方向依赖，不能以这一项代替完整摩擦研究。

这是否意味着现在可以给真机做激励运动？

不意味着。真机激励涉及速度、力矩、工作区、负载、碰撞风险、控制模式和安全审批。当前页只建立数据与模型判断框架；实施前必须由设备负责人按现场安全流程确定轨迹、限幅、监控和回退。

下一工程落点不是继续堆数学：带着“模型需有证据”的标准进入 ROS2-04～10，再在 fake hardware、标定与实际设备到位后逐级替换模型来源。
