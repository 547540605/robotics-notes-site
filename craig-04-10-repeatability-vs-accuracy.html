§4.10 重复定位精度 vs 绝对定位精度：为什么“算出来的逆解点”比“示教点”更难准？

本节要解决的核心问题：工业机械臂铭牌上常写着“重复定位精度 $\pm 0.02\text{ mm}$”，为什么当我们用视觉相机拍出一个三维坐标、通过本章逆运动学公式算出关节角命令机械臂去抓时，实际末端却可能偏出 $1\sim 3\text{ mm}$？“回人工示教点（Taught Point）”与“去逆解算出来的坐标点（Computed Point）”在误差链上到底有什么本质区别？

前因（§4.4–4.9 做了什么） 我们假定名义 DH 参数与工具变换完全准确，从目标位姿 ${}^S_G T$ 算出了理论关节角指令 $\theta^*$。
本节（§4.10 解决什么） 对比重复定位精度（Repeatability）与绝对定位精度（Accuracy），拆解逆解计算点的误差来源、外部测量方法与标定补偿手段。
后果（下一步去哪） 完成第 4 章理论闭环，可前往 ROS 2 实验 16（TCP 标定与精度） 或 12a 空间 3R 逆解。

1. 一张图看懂：“回示教点” vs “去算出来的坐标点”

Craig 在 §4.10（原书 P88–89）指出：机器人目标点有两类来源——第一类是操作员拿着示教器把机械臂摇到实物位置后直接记录关节编码器读数（示教点 Taught point）；第二类是由 CAD 离线编程、视觉相机或力控算法给出笛卡尔坐标，再调用本章 SOLVE 逆运动学算出的点（计算点 Computed point）。

图 4.10-1：左图“回示教点”不经过逆运动学，只考验机械臂每次回到同一编码器角时的离散度（重复定位精度）；右图“去逆解算出的坐标点”把名义几何模型与真实硬件之间的系统误差全部暴露出来（绝对定位精度）。

2. 指标定义、误差来源与测量方法对比

为什么“关节点读数看上去完全准了（编码器误差为 0）”，末端在世界坐标系里却没准？下表把两项指标的定义、物理根源、如何测量以及如何提升拆解清楚：

对比维度 重复定位精度（Repeatability） 绝对定位精度（Accuracy）
物理定义 命令机器人用同一组关节角指令反复返回同一位置 $N$ 次，各次实际到达点围绕其自身平均落点中心的离散半径。 命令机器人去往一个由笛卡尔坐标计算出的目标点 $P_{\text{cmd}}$，实际到达的平均中心 $\bar{P}_{\text{actual}}$ 与外部真实坐标 $P_{\text{cmd}}$ 之间的距离误差 $\|\bar{P}_{\text{actual}} - P_{\text{cmd}}\|$。
对应工作模式 在线人工示教再现（Teach & Playback）：焊装、固定工位搬运。 依赖逆运动学的离线编程（OLP）、视觉引导抓取（Eye-in-Hand / Eye-to-Hand）、CAD 轨迹直驱。
主要误差来源 随机与非建模机械回差：减速器反向间隙（Backlash）、摩擦死区、伺服编码器分辨率、结构热漂移。 系统性模型失配 + 重复误差：
1. 连杆真实长度/扭角与名义 DH 参数 $(a_i, \alpha_i, d_i)$ 的加工制造公差；
2. 关节零位偏移 $\Delta\theta_{i,0}$；
3. 连杆与减速器在重力负载下的弹性挠曲变形；
4. §4.8 中的工具 TCP ${}^W_T T$ 与工作台 ${}^B_S T$ 标定误差。
怎样测量？ 单点相对测量即可：在工作空间固定千分表（Dial indicator）、三向电涡流位移传感器或激光干涉靶球，让机器人反复进出该点读相对波动。仅看内部关节编码器无法测出真实末端重复精度！ 必须在全局外部基准系下测量：使用激光跟踪仪（Laser Tracker）、光学动作捕捉系统或高精度三坐标测量臂（CMM），统一对齐基座系 $\{B\}$ 后测量多点真实三维坐标与理论坐标的残差。
靠什么改善？ 提高减速器刚度与装配预紧、提升编码器位数、优化关节伺服环增益、恒温热平衡（软件标定无法消除随机重复误差）。 运动学参数标定（Kinematic Calibration）与手眼/TCP 标定：采集工作空间多组外部实测位姿，辨识修正真实 DH 参数、关节零偏 $\Delta\theta_0$、关节柔顺系数，或建立空间误差补偿网格表。

3. 教学数值例子：仅 $0.2^\circ$ 零偏 + $0.8\text{ mm}$ 杆长公差，会让逆解点偏多少？

说明（非验收指标声明）：以下数值仅用于演示“名义模型与真实硬件微小失配如何通过正/逆运动学放大为末端绝对偏差”的教学算例，不代表任何具体型号机器人的出厂或项目验收指标。

考虑一台平面两连杆机械臂，控制器软件里填写的名义参数为 $L_1 = 500.0\text{ mm},\; L_2 = 500.0\text{ mm}$。但真实装配好的机械臂存在两项极常见的微小系统误差：

1. 第 1 杆真实长度为 $L_1^{\text{real}} = 500.8\text{ mm}$（加工/热胀长了 $0.8\text{ mm}$），第 2 杆 $L_2^{\text{real}} = 500.0\text{ mm}$；
2. 肩关节零位定标时偏了 $\Delta\theta_1 = +0.20^\circ$（即控制器以为发的是 $\theta_1$，实际连杆转到了 $\theta_1 + 0.20^\circ$）；
3. 关节伺服与减速器本身的随机重复波动极小，仅为 $\pm 0.03\text{ mm}$。

第 1 步：控制器按名义参数求逆解

视觉相机给出笛卡尔目标点 $P_{\text{cmd}} = (500.0,\; 500.0)\text{ mm}$。
控制器用 §4.4 名义几何逆解（取下肘支）算出理论关节角： $$\theta_1^* = 0.00^\circ, \qquad \theta_2^* = 90.00^\circ$$ （名义验证：$x = 500\cos 0^\circ + 500\cos 90^\circ = 500.0\text{ mm}$，$y = 500\sin 0^\circ + 500\sin 90^\circ = 500.0\text{ mm}$。）

第 2 步：真实机械臂执行该指令后的实际落点

真实机械臂走到的物理角度是 $\theta_1^{\text{real}} = 0.20^\circ$，$\theta_1^{\text{real}}+\theta_2^{\text{real}} = 90.20^\circ$，真实落点中心 $\bar{P}_{\text{actual}}$ 为： $$\bar{x} = 500.8\cos(0.20^\circ) + 500.0\cos(90.20^\circ) \approx 500.80 - 1.75 = \mathbf{499.05\text{ mm}}$$ $$\bar{y} = 500.8\sin(0.20^\circ) + 500.0\sin(90.20^\circ) \approx 1.75 + 500.00 = \mathbf{501.75\text{ mm}}$$

$$\text{绝对定位偏差 } \|\bar{P}_{\text{actual}} - P_{\text{cmd}}\| = \sqrt{(499.05 - 500.0)^2 + (501.75 - 500.0)^2} \approx \mathbf{1.99\text{ mm}}, \qquad \text{重复定位波动 } \approx \mathbf{\pm 0.03\text{ mm}}$$

看懂这个反差：如果你让这台机械臂反复去抓这个计算点 100 次，它每次都会稳稳停在 $(499.05 \pm 0.03,\; 501.75 \pm 0.03)\text{ mm}$ 处（重复定位精度高达 $\pm 0.03\text{ mm}$），但它离你真正想抓的 $(500.0, 500.0)\text{ mm}$ 始终差了将近 $2\text{ mm}$！如果换成人工摇示教器对准 $(500,500)$ 实物点记录编码器，操作员在示教那一刻就已经肉眼补偿了那 $0.20^\circ$ 和 $0.8\text{ mm}$，再现时就只剩下 $\pm 0.03\text{ mm}$ 的重复误差。

4. 适用边界与工程改进路线

什么时候必须做标定或闭环修正？

• 纯示教工位（固定夹具上下料）：重复定位精度够高即可，通常不需要做复杂的本体 DH 标定。
• 视觉引导 / 离线编程 / 跨机器人程序移植：强依赖逆解计算点的绝对精度，必须依次排查：
 1. 工具 TCP 标定（修正 ${}^W_T T$）；
 2. 手眼与工作台标定（修正 ${}^B_S T$）；
 3. 机械臂本体零位与 DH 参数标定，或在末端引入视觉伺服（PBVS/IBVS）与力控柔顺引导消除残余偏差。

5. 本节结论与随堂自检（点击展开答案）

本节一句话结论：“回示教点”绕开了运动学模型，只考验机械与伺服的重复定位精度；“去逆解计算点”则把本体 DH 公差、零位偏移、连杆变形和工具/工作台标定误差全部串联进来，直接受限于绝对定位精度。
自检题 1：为什么同一台工业机械臂的“重复定位精度”几乎总是比它的“绝对定位精度”高出一个数量级以上？
因为重复定位精度只反映单次往返同一关节角时的随机机械回差与伺服抖动；而绝对定位精度还叠加了连杆长度公差、关节零位偏移、重力挠曲变形、TCP 与工作台标定残差等所有系统性模型误差。
自检题 2：能不能只读取机器人自带的关节光电编码器数值，代入正运动学公式算出末端坐标，来评估这台机器人的绝对定位精度？
不能！用机器人自己的编码器读数代入名义正运动学，只能算出“控制器以为末端在哪里”，完全看不出连杆加工公差、零偏、齿轮背隙和连杆弯曲造成的真实空间偏差。测量重复精度和绝对精度都必须借助千分表、激光跟踪仪或光学动捕等外部独立测量仪器。
自检题 3：通过激光跟踪仪做完高精度运动学标定（修正了软件里的 DH 参数和零偏）之后，机器人的绝对定位精度和重复定位精度分别会怎么变？
绝对定位精度会显著提升（靶心偏移 $\Delta P$ 被软件模型补偿掉，平均落点中心回到真实目标附近）；但重复定位精度基本不变，因为软件参数标定无法消除减速器间隙、摩擦和传感器噪声等随机硬件波动。
自检题 4：在一条产线上，把 A 机器人示教好的关节角程序直接复制到同型号的 B 机器人上运行，结果 B 机器人抓偏了 $2\text{ mm}$。这属于重复定位精度问题还是绝对定位精度问题？
属于绝对定位精度（及工装基准标定一致性）问题。不同机器人的个体零偏、连杆微小公差以及底座相对工作台的安装位姿 ${}^B_S T$ 并不完全相同，跨机复用程序等价于依赖名义模型去到达空间坐标点，必须经过底座/工具重标定或本体绝对精度标定。
