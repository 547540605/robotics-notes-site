笔记 39：上位轨迹如何变成关节力矩——伺服三环、驱动器与接口边界

机械臂算法工程师常说“给关节一个位置”，但实际电机不认识弧度目标。它通过编码器、电流测量、驱动器和传动链，在多个闭环中逐级把位置误差变成电流，再变成力矩。本页建立层级边界：哪一环通常在驱动器内，ROS/规划器通常交给哪一层，什么参数不应在不了解设备时盲调。

从任务到电流，不是一条跳跃的线

位置环e_q → q̇_cmd
速度环e_qdot → τ_cmd
电流环τ_cmd → i_q
逆变器/电机i_q → τ_motor

图中从右向左是反馈；具体谁实现哪一环取决于驱动器、控制柜和厂商接口。不要把示意图中的环路频率、参数或通信协议当成所有设备的通用真值。

1. 三层闭环各自只解决一个问题

层典型输入/输出通常在哪里核心风险
电流/力矩环i_q_cmd → i_q；再经力矩常数得到 τ伺服驱动器固件，通常最快电流、功率器件、过流与保护；不能由上位机随意绕过。
速度环q̇_cmd - q̇ → 力矩/电流命令驱动器或控制柜阻尼不足会振荡；编码器噪声、传动弹性与负载影响明显。
位置环q_d - q → q̇_cmd 或努力量驱动器、机器人控制柜或上位控制器行程/速度边界、轨迹时间语义、谁拥有最终限幅必须明确。
最重要的边界：ROS 2 的轨迹控制器、MoveIt 或你写的算法，通常只向设备暴露的 position/velocity/effort 接口发送参考；它们不自动取得电流环控制权。接口层级必须从厂商驱动和 ros2_control 的 command interface 里确认，不能从话题名称猜。

2. 同一个角度单位，跨过传动链后也不能想当然

q_joint = q_motor / N + q_offset,   τ_joint ≈ ηNτ_motor

N 是减速比，η 是传动效率的简化表示。编码器读数、驱动器电机角和 URDF 关节角并非天然是同一量；零位偏置、正方向、齿隙与柔性也会改变二者关系。这是“URDF 关节方向正确、现场却反着动”时必须先核查的链条。

4. 现场调试不是“从位置环开始调”

  1. 先确认机械与安全：抱闸、限位、急停、使能、负载、软硬限位和允许运动空间由设备流程确认。
  2. 再确认反馈语义：编码器增量方向、零位、减速比、关节角单位与速度符号；小幅受控动作必须与读数同向。
  3. 电流/力矩环：通常遵循厂商调试工具和保护边界；上位算法只核对可用 effort 接口与测得力矩语义。
  4. 速度环：先获得足够阻尼和可控响应，再处理位置外环；不要用巨大的位置 Kp 掩盖内环不稳。
  5. 位置环和轨迹：最后结合速度/努力/行程限制、负载、重力和摩擦前馈调节；每次改变保留参数版本和回退路径。

5. 与 ROS 2 / ros2_control 的精确连接

你需要核对的不是“有没有 topic”

  • Hardware Interface 暴露的是 position、velocity 还是 effort command；
  • state interface 是否包含新鲜的 position/velocity/effort；
  • 控制器是否 active、是否 claim 正确关节接口；
  • JointTrajectory 的 time_from_start、速度/加速度字段和容差如何被设备解释。

常见错误归属

  • 规划成功但 Action 执行失败：多查控制器、接口、限幅、使能和状态；
  • 实际误差长期偏置：多查负载、重力/摩擦前馈、积分策略与力矩边界；
  • 响应振荡：多查速度环阻尼、结构共振、采样/滤波，不先无限加位置 Kp。
为什么不在 ROS 节点里自己写“电流环”？

电流环通常要求驱动器级的实时性、PWM/采样同步与硬件保护，且与具体功率器件紧密耦合。除非设备和项目明确授权、具备相应实时硬件与安全设计，否则上位 ROS 节点不应假装接管该层。

能否把 position、velocity、effort 三种接口同时随意写？

不能。可同时暴露哪些 command interface、由哪个控制器 claim、它们是否可组合，取决于硬件驱动和控制器配置。接口冲突时应由 controller_manager 的 lifecycle/claim 状态拒绝，而不是靠业务节点“最后一次写入”决定。

这页的教学仿真为何没有电流 PI？

它故意把电流环抽象为“已稳定实现的努力”，把可见重点放在位置环、速度环与两级限幅的因果关系。要学习驱动器固件级电流控制，需要以具体电机、逆变器、采样频率和厂商文档为边界，不能从这个简化模型外推真机参数。

下一项补齐 JD 的工程诊断能力：40 扫频、频响、带宽与机械共振定位。它会解释为什么“位置环一加大就抖”有时不是 PID 算错，而是结构与传动链在响应。
